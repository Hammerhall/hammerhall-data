# hammerhall-data

Открытые наборы данных для кузен Hammerhall — Stream Forge, а дальше асинхронной, реактивной
и многопоточной. Сами данные лежат в **выпусках** (Releases) этого репозитория: в git их нет, чтобы
репозиторий оставался лёгким. Кузня скачивает нужный набор сама при первом обращении и сверяет
контрольные суммы.

## Наборы

| выпуск | что | объём | лицензия |
|---|---|---|---|
| `air-data-v1` | авиаперевозки: 73 аэропорта сети в 17 странах (в справочнике — 5 501 аэропорт мира), 135 571 рейс за два года, 8,5 млн броней, 18,4 млн билетов, 24 млн перелётов, 23 млн посадочных талонов; сезонность по регионам и праздникам | ≈ 790 МБ, 9 файлов TSV.gz | MIT © 2025 Postgres Professional |

Каждый набор — папка в репозитории: как собран (скрипт сборки), что в нём (`SOURCE.md`), чья
лицензия (`LICENSE`). Сборка повторяема: тот же скрипт на ту же исходную выгрузку даёт то же
содержимое — проверяется `check_air_data.py`.

## Состав выпуска

* таблицы — `*.tsv.gz`: UTF-8, табуляция, заголовок в первой строке, пустое поле — NULL;
* `manifest.json` — версия, число строк, контрольные суммы (`sha256` — файла, `sha256_tsv` —
  содержимого), модель отбора;
* `SOURCE.md` — источник, что изменено против исходной выгрузки, поля таблиц;
* `LICENSE` — лицензия данных.
