### Кино: фильмы и жанры, актёры и роли, режиссёры, страны и языки фильмов

#### `movies` — Фильмы Wikidata: художественные, короткометражные, анимационные, документальные, телефильмы, немые — без фильмов для взрослых; с годом выхода и названием

Ключ — `id`; строки упорядочены по `id`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `id` | int |  | Фильм — номер элемента Wikidata (Q42 → 42) | Wikidata |
| `title` | text |  | Название: метка en, иначе mul, иначе P1476, иначе метка запасного языка | Wikidata, как есть |
| `title_ru` | text | да | Название по-русски (метка ru) | Wikidata, как есть |
| `year` | smallint |  | Год выхода: самая ранняя дата P577 с точностью не ниже года | Wikidata, правило набора |
| `release_date` | date | да | Дата выхода: самая ранняя дата P577 с точностью до дня | Wikidata, правило набора |
| `runtime` | int | да | Хронометраж, минуты (P2047) | Wikidata, правило набора |
| `rank` | decimal |  | Рейтинг 1.0–9.9 — синтетический: из открытых признаков Wikidata и шума от seed, не оценка качества | генератор |
