#
# Разметка шаблона:
#   [а|б|в]   — один из вариантов (пустой вариант — ничего), группы вкладываются;
#   <м|ж|с>   — по роду названия жанра {G}: «хороший боевик», «хорошая комедия», «хорошее фэнтези»;
#   {T}       — название фильма в «ёлочках»;  {O} — другой фильм (того же режиссёра или серии) в «ёлочках»;
#   {D}       — режиссёр;  {A}, {B} — актёры;  {Y} — год;  {DEC} — десятилетие («1990-х»);
#   {G}, {Gg} — жанр (именительный, родительный);  {Gp}, {Gpg} — жанры во множественном (им., род.);
#   {N}       — оценка числом;  {Nb} — оценка с «баллом» («8 баллов», «3 балла»).
# Шаблон с полем, которого у фильма нет, не берётся.
#
# Тон: R — 9–10 (восторг), G — 7–8 (хорошо), M — 5–6 (средне), D — 3–4 (разочарование), H — 1–2 (резко, но без
# оскорблений). Аспекты: .p2 — восторженно, .p1 — хорошо, .n1 — мягкая критика, .n2 — резкая критика.
# Правила текста: зритель о себе — без прошедшего времени (род неизвестен): «смотрю», «мне понравилось»,
# «не жалею»; режиссёр — «режиссёр … снял»; имена — только в именительном («{A} играет», «— {A}»); название в
# косвенном падеже — только после слова «фильм» («после фильма {O}»). Критикуется только работа: сценарий,
# монтаж, темп, — не люди. Имена людей ({A}, {B}, {D}) — только в похвале и нейтральных предложениях (.p2, .p1):
# актёры и режиссёры настоящие, а рецензии выдуманы; минус и критика — безлично («режиссура местами тяжеловесна»,
# «актёрам не хватает материала»): минусы аспектов актёра, дуэта и режиссёра берутся из cast.n* и direction.n*.
