# sto-data-v1 — поля

### Каталог

#### `categories` — Категории — дерево с одним корнем, до 6 уровней

Ключ — `id`; строки упорядочены по `id`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `id` | int |  | Категория | генератор |
| `parent_id` | int → `categories` | да | Родительская категория; NULL — корень | генератор |
| `level` | smallint |  | Уровень: 1 — корень, 6 — самый глубокий | генератор |
| `name_ru` | text |  | Название по-русски | генератор |
| `name_en` | text |  | Название по-английски | генератор |

#### `spec_keys` — Справочник характеристик товаров (ключи EAV)

Ключ — `key`; строки упорядочены по `key`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `key` | text |  | Код характеристики | генератор |
| `name_ru` | text |  | Название по-русски | генератор |
| `name_en` | text |  | Название по-английски | генератор |
| `unit` | text | да | Единица (латиницей: in, GB, W, mAh…); NULL — без единицы | генератор |
| `value_type` | text |  | Тип значения: `num`, `text` | генератор |

#### `brands` — Бренды — все выдуманные

Ключ — `id`; строки упорядочены по `id`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|

| `name_en` | text |  | Название по-английски | генератор |
| `model_line` | text |  | Модельная линейка | генератор |
| `generation` | smallint |  | Поколение модели в линейке: 1, 2, … | генератор |
| `launched_on` | date |  | Начало продаж | генератор |

Ключ — `product_id, key`; строки упорядочены по `product_id, key`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `product_id` | int → `products` |  | Товар | генератор |

| `value_num` | decimal | да | Числовое значение | генератор |
| `unit` | text | да | Единица числового значения (как в spec_keys) | генератор |

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `bundle_id` | int → `products` |  | Комплект | генератор |

| `qty` | smallint |  | Штук в комплекте | генератор |

#### `prices` — История розничных цен магазина: периоды [valid_from, valid_to) без разрывов и наложений

Ключ — `product_id, valid_from`; строки упорядочены по `product_id, valid_from`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `product_id` | int → `products` |  | Товар | генератор |
| `valid_from` | moment |  | Цена действует с (включительно) | генератор |
| `valid_to` | moment | да | Цена действует по (исключая); NULL — без конца в периоде | генератор |
| `price` | money |  | Цена с НДС, руб. | генератор |

#### `promotions` — Акции: скидки, промокоды, «n+m», комплекты; периоды пересекаются

Ключ — `id`; строки упорядочены по `id`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `id` | int |  | Акция | генератор |
| `kind` | text |  | Механика: `percent`, `amount`, `n_plus_m`, `bundle`, `promocode` | генератор |
| `name_ru` | text |  | Название по-русски | генератор |
| `name_en` | text |  | Название по-английски | генератор |
| `event` | text | да | Торговое событие календаря; NULL — обычная акция: `eleven_eleven`, `black_friday`, `new_year`, `winter_sale`, `feb23`, `mar8`, `may_holidays`, `summer_sale`, `back_to_school` | генератор |
| `discount_pct` | decimal | да | Скидка, % (percent, bundle, promocode в процентах) | генератор |
| `discount_amount` | money | да | Скидка, руб. (amount — с единицы товара; promocode без целей — с заказа) | генератор |
| `buy_qty` | smallint | да | n+m: сколько купить | генератор |
| `free_qty` | smallint | да | n+m: сколько из них бесплатно (самые дешёвые) | генератор |
| `promo_code` | text | да | Промокод (только promocode) | генератор |
| `min_order_amount` | money | да | Минимальная сумма заказа | генератор |
| `valid_from` | moment |  | Начало (включительно) | генератор |
| `valid_to` | moment |  | Конец (исключая) | генератор |
| `stackable` | bool |  | Суммируется с другими суммируемыми акциями | генератор |

#### `promotion_targets` — На что действует акция: товар или категория (с поддеревом); у акции без строк — весь заказ

Ключ — `promo_id, seq`; строки упорядочены по `promo_id, seq`.

| поле | тип | NULL | что | откуда |
|---|---|---|---|---|
| `promo_id` | int → `promotions` |  | Акция | генератор |
| `seq` | int |  | Номер цели в акции: 1, 2, … | генератор |
| `product_id` | int → `products` | да | Товар | генератор |
| `category_id` | int → `categories` | да | Категория (действует на всё поддерево) | генератор |
